# Une seule regle pour TOUS les agents, presents et futurs.
#
# Les dix agents nommes qui figuraient ici ont ete retires le 22.10.2026 :
# la note normative d'AgentReady (AR-FIND, « Crawl policy ») demande l'inverse
# d'une liste blanche. Deux raisons, l'une immediate et l'autre differee.
#   · Les agents passent aussi par des API de recherche — Brave, Exa, Parallel,
#     Tavily — qui ont leurs propres robots. Le joker les couvre, une liste de
#     noms non.
#   · Un groupe nomme PRIME sur le groupe « * » (RFC 9309). Tant que tous
#     disaient « Allow: / », l'effet etait nul ; le jour ou l'on ajoute un
#     Disallow au joker, les dix nommes ne l'heritent pas. La liste blanche
#     creait donc un piege differe, pas une protection.

# Content-Signal (contentsignals.org) — une DECLARATION, pas un blocage.
# Elle cree une position opposable ; aucun crawler n'en est techniquement empeche.
#
# Le defaut de l'industrie (Cloudflare) est « ai-train=no, search=yes, ai-input=no ».
# On s'en ecarte sur UN point, deliberement : ai-input designe le fait d'alimenter
# une reponse d'IA — c'est-a-dire exactement se faire citer par ChatGPT ou Perplexity.
# Le refuser contredirait la raison d'etre du llms.txt, des miroirs markdown et de
# l'ai-catalog de ce site, qui existent pour etre lus par des agents.
#   search=yes    · indexation et renvoi vers la page
#   ai-input=yes  · servir de source a une reponse generee, avec citation
#   ai-train=no   · pas d'entrainement ni de fine-tuning sur ce contenu

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /

Sitemap: https://marwanbridi.com/sitemap-index.xml
